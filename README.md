# 🏡 Airbnb Clone (SwiftUI)

**Created by Tarun Tanwar**

A native iOS Airbnb-inspired application built with **SwiftUI** and **iOS 17**. This project is part of my journey to learn modern iOS development by building real-world applications using reusable components, scalable project structures, and clean architecture principles.

## ✨ Current Features

* SwiftUI-based user interface
* Modular folder architecture for scalability
* Explore screen built with `NavigationStack`
* Scrollable property feed using `ScrollView` and `LazyVStack`
* Reusable property card component (`ListingItemView`)
* Organized feature-based project structure
